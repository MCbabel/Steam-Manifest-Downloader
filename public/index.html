📊 Help improve the app?

We'd like to collect anonymous usage statistics so we know which features to invest in.

✅ We collect

  • App version, OS, architecture
  • Which features get used (counters only)
  • A random install ID (not tied to you)

🚫 We never collect

  • Game IDs, depot IDs, file names
  • Contents of .lua / .st files
  • IP addresses, account info

Events are end-to-end encrypted with a public key embedded in the app — only the maintainer's server can decrypt them. You can change your choice anytime in Settings → Advanced Settings.
